# PromaRacer

Гоночный симулятор в браузере: от дорожного GTR до Формулы 1. Телефон в картонных VR-очках (гироскоп для обзора), руль, газ, тормоз и передачи на M5Stack Cardputer ADV.

## Что внутри
| Файл | Назначение |
|---|---|
| `index.html` | страница игры (меню, результаты) |
| `js/cars.js` | 6 классов: Road GT (GTR), GT3, Формула 4, 3, 2, 1: мощность, масса, передачи, аэродинамика, тормоза |

**Промокоды** (Профиль -> Промокод): `speed` открывает все машины с апгрейдами на максимум, `garage` открывает все машины без улучшений. Новые коды добавляются в `PROMOS` в `js/cars.js`.
| `js/track.js` | 5 замкнутых трасс: Proma Ring (4 км), Proma Sprint (2,3 км), Proma Forest (лес), Proma Streets (город, стены), Proma Coast (побережье, пальмы); у каждой своё небо, земля, окружение |
| `js/physics.js` | динамика: перенос веса, сцепление шин по осям, прижимная сила, нагрев и износ шин, ABS, коробка, отбойник |
| `js/ai.js` | соперники: едут по профилю скорости, рассчитанному по кривизне трассы |
| `js/input.js` | клавиатура/Cardputer, гироскоп |
| `js/render.js`, `js/audio.js`, `js/main.js` | графика (Three.js), звук, гонка (в т.ч. удалённые игроки) |
| `js/ui.js`, `js/lobby3d.js` | лобби: загрузка, вход, гараж, профиль, настройки, комнаты, друзья и чат; 3D-гараж пит-стопа на фоне |
| `js/net.js`, `js/config.js` | Supabase: аккаунты, профиль, друзья, чат, онлайн-комнаты (Realtime) |
| `supabase/schema.sql` | таблицы, политики доступа и функции награды/покупки |
| `firmware/PromaWheel/PromaWheel.ino` | прошивка Cardputer ADV |
| `tests/*.js` | проверки без браузера: `sim.js` (круги ИИ), `accel.js` (разгон/торможение), `handling.js` (руль на скорости), `smoke.js` (вся гонка), `touch.js` (режим касания), `spin.js` (заносы) |

## Управление
| Действие | Cardputer | Клавиатура компьютера |
|---|---|---|
| Руль | наклон Cardputer | A / D |
| Газ / тормоз (держать) | `9` / `o` | W / S |
| Передача выше / ниже | `0` / `p` | E / Q |
| Авто / ручная коробка | | N |
| Вернуть на трассу | | R |
| Помощники вкл/выкл | | Пробел |
| Вид сзади / из кокпита | | V |
| Пауза | | Esc |
| Ручник (свободная езда) | кнопка `.` | Shift |
| Старт / меню после финиша | | Enter |

В меню выбираются класс машины, трасса, число кругов, соперники (0–7) и коробка. Тап по экрану в игре выравнивает взгляд вперёд.

## Режим «Телефон, касанием» (без клавиатуры и Cardputer)
В меню нажми **«Старт: телефон, касанием»** (телефон горизонтально, один экран, без VR).
- **Газ** и **тормоз** — большие кнопки справа внизу, **▲ / ▼** над ними — передачи (в ручной коробке).
- **Руль на экране** (по умолчанию): круглый руль слева внизу, тяни обод по кругу (до ~135 градусов), отпустил и руль сам вернулся в центр. Вид из кокпита при этом поворачивается гироскопом телефона, кнопка ⌖ вверху задаёт «прямо». Паузу (⏸ или Esc) можно закончить кнопкой «В меню».
- **Руль наклоном:** выбирается в настройках; тогда телефон занят рулём и обзор гироскопом отключён. Наклон телефона, как баранка: держи телефон экраном к себе и поворачивай. Нейтраль запоминается при зелёном «GO!» и по кнопке ⌖ вверху; полный руль при повороте на ~55°. Если руль крутится наоборот, в меню включи «Инверсия руля». Режим «Руль: кнопки ◀ ▶» даёт экранные кнопки вместо наклона.
- Сверху: ⏸ пауза, 👁 вид из кокпита / сзади, A/M авто или ручная коробка, ↺ вернуть на трассу.
- iPhone спросит доступ к датчикам движения: разреши. Для полноэкранного режима добавь страницу на экран «Домой» (Поделиться → На экран «Домой»).

## Помощники и гироскоп
- **Помощники (по умолчанию включены):** антипробуксовка, ABS и стабилизация. Они гасят газ и тормоз, когда задняя ось начинает скользить, и держат машину по направлению руля. Выключить можно в меню, в игре клавишей Пробел или кнопкой ABS в режиме касания. Без помощников машина ведёт себя жёстче: Формулы и мощные GT при сбросе или торможении в повороте можно развернуть.
- **Обзор гироскопом** можно отключить в меню («Обзор гироскопом: ВЫКЛ»): тогда взгляд всегда вперёд, а на компьютере и в режиме одного экрана осматриваться можно мышью. Режим касания (телефон как руль) гироскоп для обзора не использует.
- Проверка устойчивости: `node tests/spin.js 1` (с помощниками) и `node tests/spin.js 0` (без). С помощниками угол увода задней оси во всех сценариях не больше 0,12 рад.

## Открытый город (без трассы)
Режим выбирается в Играть -> Offline -> **🏙 Открытый город**. Большой город 1,1 км (кварталы, улицы, большая центральная площадь для заносов, стена по границе), без кругов и соперников. Машина — выбранная в гараже. Тормоз у остановки включает задний ход. **Ручник:** Shift или «.» на клавиатуре, или кнопка «РУЧНИК» в режиме касания. Помощники в этом режиме выключены (Пробел включает), задняя ось чуть «живее». Очки за дрифт: угол скольжения × скорость, серия растёт, пока занос не прервался, множитель до x6; удар о здание обнуляет серию. Дым и следы от шин, R — вернуть на площадь. Проверка: `node tests/open.js gt3`.

## Как играть
- Шины работают в своём окне температур (на экране: синие холодные, зелёные в норме, жёлтые и красные перегретые). Холодные шины и износ снижают сцепление.
- У Формул прижимная сила растёт со скоростью: в быстрых поворотах сцепления больше, чем на малой скорости. ABS есть только у GTR и GT3, на Формулах тормоз можно заблокировать.
- **Приборка на экране** (вид сзади): BEST/LAST, круг, позиция, время сессии, текущий круг и дельта к лучшему, круглый тахометр со скоростью, передачей и педалями. В дождь у машин брызги из-под колёс, горят стопы.
- **Призрак:** после первого круга по трассе едет голубая полупрозрачная копия твоей машины по записи лучшего круга; дельта на приборке считается относительно неё.
- **Кино-эффекты** (Настройки -> Графика): свечение ярких мест, виньетка, зерно плёнки, цветокоррекция, хроматическая аберрация и радиальное размытие на скорости, растяжение поля зрения и покачивание головы от перегрузок. Если телефон тормозит, включи «Простая».
- **Дождь** (Настройки -> Погода, только офлайн): мокрая трасса, сцепление падает на ~30% (с ростом скорости — аквапланирование), пасмурное небо, туман, струи дождя. Формулы едут на дождевых шинах и теряют меньше. Круг F1 на Proma Ring: ~82 с вместо 68 с.
- Слипстрим: за машиной впереди сопротивление воздуха меньше.
- Если застрял на траве или развернуло, через 3 секунды «маршалы» вернут машину на трассу; можно и вручную клавишей R.

## Запуск на телефоне
Гироскопу iPhone нужен HTTPS: включи GitHub Pages (Settings -> Pages -> Deploy from a branch -> `main` / root). Игра: `https://maxprotop-1.github.io/promaracer/`. Нужен интернет для загрузки Three.js с cdnjs.

## Прошивка Cardputer ADV
1. Arduino IDE 2.x. Preferences -> Additional boards manager URLs: `https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json`.
2. Boards Manager: пакет **M5Stack**, плата **M5Cardputer**.
3. Library Manager: **M5Unified**, **M5GFX**, **M5Cardputer**, **SparkFun BMI270 Arduino Library**.
4. BLE-клавиатура (класс `BleKeyboard`): для ядра ESP32 2.0.x **ESP32 BLE Keyboard** (T-vK); для 3.x NimBLE-версия **ESP32-NimBLE-Keyboard** с **NimBLE-Arduino 1.4.x** (ставятся из ZIP).
5. Открой `firmware/PromaWheel/PromaWheel.ino` (папка должна называться `PromaWheel`), Tools -> USB CDC On Boot: Enabled, выбери порт, Upload. Если порт не виден: выключи Cardputer, зажми G0, включи, отпусти G0.
6. iPhone: Настройки -> Bluetooth -> **PromaRacer Wheel**. В меню игры видно последнюю клавишу и положение руля.

Служебные клавиши Cardputer (в игру не уходят): `Enter` текущее положение = «прямо», `Del` перевернуть направление руля, `1` сменить ось, `[` `]` угол поворота до упора (по умолчанию 90 градусов).

## Что проверено, а что нет
Проверено в node: физика, ИИ, круги, результаты, полная гонка (`node tests/smoke.js f1 0`). Графика (Three.js) и звук проверены только на отсутствие ошибок в коде с заглушкой, внешний вид на экране и на телефоне ещё не видел никто. Прошивка на устройстве не запускалась.


## Лобби, аккаунты и онлайн
Схема экранов: загрузка (колесо) -> вход / гость -> лобби (Играть, Гараж, Профиль, Друзья, Настройки) -> Играть -> Online (создать комнату / войти по коду) или Offline -> выбор режима (Гонка / На время) -> игра.
- **Гараж:** 6 классов, цена в монетах, три апгрейда (двигатель, шины, аэродинамика) до 5 уровня. Монеты даются за гонки.
- **Онлайн:** хост создаёт комнату (код из 5 символов), выбирает трассу, круги, режим и «все на GT3 / F3», друзья входят по коду. Данные идут через Supabase Realtime (broadcast 20 раз в секунду + presence), отдельного сервера нет.
- **Друзья:** добавление по нику, заявки, статус онлайн, личный чат.

### Настройка Supabase (один раз)
1. SQL Editor -> вставь и выполни `supabase/schema.sql`.
2. Authentication -> Providers -> Email: оставь **Confirm email включённым** (защита от спама: аккаунт работает только после подтверждения почты). В URL Configuration -> Site URL укажи адрес игры.
3. Project Settings -> API -> скопируй **anon public** ключ в `js/config.js` (`SUPABASE_ANON_KEY`). Он публичный, его можно коммитить. Без ключа игра работает офлайн с гостевым профилем.

Проверка логики лобби и онлайна без браузера: `node tests/ui.js`.


## Свободная езда (город, дрифт)
Играть -> Offline -> режим **«Свободная езда»**: город Proma Streets без кругов, соперников и столкновений, дорога шире (36 м), чтобы было где кататься. Дрифт-настройка (по умолчанию включена): задний привод, мягче задняя ось, больше угла руля для контрруля, помощники выключены. Ручник: Shift (компьютер), `.` (Cardputer) или кнопка РУЧНИК на экране телефона.
Очки идут, пока задняя ось скользит под углом больше ~10 градусов на скорости выше 25 км/ч. Серия растёт: множитель ×1 ... ×5 (каждые 2 секунды заноса), пауза до 1,2 с не рвёт серию, удар об стену обнуляет её. Рекорд серии виден в профиле. Погода (дождь) тоже работает. Только офлайн.
