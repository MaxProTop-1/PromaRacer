PROMARACER

Сначала в настройках Bluetooth телефона подключи «PromaRacer Wheel» (Cardputer), потом нажми кнопку ниже. Крути руль и жми 9 / o / 0 / p, чтобы проверить связь.
Руль: нет сигнала
Последняя клавиша: —
Газ 0 · Тормоз 0 · Передача 1
Телефон горизонтально. Тап по экрану в игре — выровнять взгляд вперёд.
Тест с клавиатуры (компьютер): Enter — старт, ← → руль, ↑ газ, ↓ тормоз, X / Z — передача выше / ниже.
Мышью (зажать и двигать) можно осмотреться. После финиша — клик/тап, чтобы поехать заново.
